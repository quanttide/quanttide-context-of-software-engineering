# 量潮软件工程语境

量潮软件工程的语境材料集，汇集领域内的意图、洞察、教程与案例，作为人机协作与评审的上下文。

它针对的问题是：AI 拿不到设计者的意图，只能从代码里归纳，于是把「先放着的」当成「深思熟虑的」。把意图与参照物写成材料，评审才有对照物，AI 才不至于退回通用代码规范。

材料按分类组织；同一分类下有多个范围时以子目录区分，`default` 为默认范围：

- `intention`——意图，人机分工与平台定位；
- `insight`——洞察，评审方法与意图显式化；
- `tutorial`——教程，intent / lint / review / reflect / refactor 各环节；
- `essay`——随笔；
- `gallery`——概念辨析与对照；
- `library`——参考资料；
- `profile`——画像。
